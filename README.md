# Invoice Master

Invoice Master is a POS-style Android application designed for full business control and management. It provides a complete system for handling stock, orders, and invoicing, optimized for responsive Android devices.

---

## Features

- Full POS system for managing products, stock, orders, and invoices  
- Real-time inventory tracking and structured data handling  
- Invoice generation and order processing workflow  
- Responsive Android UI optimized for different screen sizes  
- Business-level control for daily operations and management  

---

## Tech Stack

- Java (Android Development)  
- XML (UI Design)  
- PHP (Backend APIs)  
- SQL Database (Data Storage & Management)  

---

## Project Type

Android business management system (POS + invoicing + stock control)

---

## Purpose

This project was built to simulate a real-world business management system, focusing on operational efficiency, structured data handling, and scalable system design for companies.
